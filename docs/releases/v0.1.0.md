# Bindicator v0.1.0 — first public release

Bindicator is a free, self-hosted bin collection reminder for Debian/Linux
that uses Philips Hue lighting to show upcoming collections.

## Highlights

- **Calendar sources:** North Yorkshire Council and generic HTTPS iCalendar
  feeds (including Zoho, Google Calendar and Outlook), with support for
  additional trusted Python providers.
- **Hue reminders:** multiple Bridges, configurable colours and priority,
  spread or cycle behaviour, gradient-aware lighting and careful restoration
  of previous light state.
- **Web management:** eight-tab HTTPS dashboard for setup, schedules,
  calendar refresh, mappings, status and temporary test previews.
- **Automation:** systemd services and timers, authenticated local API,
  verified calendar caches and configurable refresh intervals.
- **Optional Alexa:** the custom skill uses the invocation **Bin Buddy**
  for next-bin questions, reminder control and bins-out confirmation, with
  Echo Show APL support. Each installation needs its own configured backend.
- **Build provenance:** the Help tab can display the exact installed
  commit alongside `0.1.0`.

## Install (Debian 13 or compatible Linux)

Prerequisites: Python 3.11+, systemd, a Philips Hue Bridge and compatible
lights, network access, and Python virtual environment support.

```bash
sudo apt-get update
sudo apt-get install -y git python3 python3-venv

git clone https://github.com/accidentalskeleton/bindicator.git ~/code/bindicator
cd ~/code/bindicator
git checkout v0.1.0
sudo bash deploy/install.sh
```

The installer provisions a dedicated service user, dependencies and systemd
units. Initial Hue pairing, calendar provider selection, colours and event
mappings must be configured afterwards. Read
[README.md](https://github.com/accidentalskeleton/bindicator/blob/v0.1.0/README.md)
and the [documentation index](https://github.com/accidentalskeleton/bindicator/blob/v0.1.0/docs/README.md).

For existing installations, back up configuration/state before upgrading;
the installer is intended to preserve these files.

## Important security notes

- The web dashboard is for your **trusted LAN only**; never expose its HTTPS
  port (default 18051) through a public tunnel. It has no separate login.
- The authenticated API listens on localhost by default (port 18050);
  do not expose it directly.
- Store Hue keys, calendar feed URLs, API tokens and AWS/Cloudflare
  credentials only in private local configuration—not in Git.
- Alexa, Cloudflare and AWS integrations are optional, separately configured
  by the operator. The original author's private skill is not a shared service.

## Known limitations

- This is a **source-based installation**; no Debian package, APT repository
  or hosted service is provided.
- Third-party calendar provider code must be trusted and reviewed before
  installation; its settings do not automatically receive a generic form.
- Security still depends on LAN isolation and administrator control of
  configuration access.
- Integration behaviour should be validated against your own Hue hardware
  and Alexa/AWS environment; automated tests cannot establish live hardware
  or cloud service operation.
